🚀 CÁCH CHẠY ỨNG DỤNG:

Phương pháp 1: IntelliJ IDEA (Nhanh nhất)
──────────────────────────────────
1. File > Settings > Build, Execution, Deployment > Application Servers
   → Thêm Tomcat Server
2. Run > Edit Configurations > Tomcat Server > Local
   → Deployment: Thêm tu_dien-1.0-SNAPSHOT.war
   → Application context: / (trống)
3. Click Run hoặc Shift+F10
4. Truy cập: http://localhost:8080/

Phương pháp 2: Deploy vào Tomcat (Truyền thống)
────────────────────────────────────────────────
1. Download Tomcat 9+ từ: https://tomcat.apache.org/download-90.cgi
2. Giải nén vào C:\Program Files\tomcat9
3. Copy WAR:
   copy build\libs\tu_dien-1.0-SNAPSHOT.war C:\Program Files\tomcat9\webapps\ROOT.war
4. Start Tomcat:
   C:\Program Files\tomcat9\bin\startup.bat
5. Truy cập: http://localhost:8080/

✅ KHOẢNG CÁCH LOGIC XẢY RA:

User truy cập localhost:8080/
    ↓
DispatcherServlet nhận request
    ↓
Gọi DictionaryController.home()
    ↓
Trả về "index" view (index.jsp)
    ↓
JSP hiển thị form tra cứu
    ↓
User nhập từ → Submit form
    ↓
POST /search
    ↓
DictionaryController.search() xử lý
    ↓
Tra cứu HashMap
    ↓
Tìm thấy? Yes → Truyền meaning vào Model
          No  → Truyền error message vào Model
    ↓
Trả về index.jsp với dữ liệu
    ↓
JSP kiểm tra found? → Hiển thị kết quả (xanh/đỏ)
